# 背景缓存生命周期检查（2026-10-20）

发现并修复了原始壁纸图片无上限保留的问题。检查覆盖深浅主题、壁纸、玻璃模式、普通背景、窗口尺寸变化、取消、解码失败和组件卸载。

## 修复的问题

- 原始壁纸使用模块级 `Map<string, Promise<HTMLImageElement>>`，没有容量上限，也不随缓存控制器卸载清理。改为控制器持有的最近使用缓存，最多 2 张原始壁纸，淘汰或卸载时移除图片 `src` 和事件处理器。
- 图片或纹理解码未完成时，旧任务仅标记取消，仍可能继续等待。现在取消会立即结束应用层等待并清理图片；反复请求同一 URL 也不会积累等待中的旧任务。
- 一张纹理解码失败时，现在同时取消另一张尚未完成的纹理解码，并释放两张纹理的 Blob URL。
- 液态玻璃替换背景或销毁时，显式取消尚未完成的背景图片请求；图片加载完成后立即移除事件处理器，避免保留控制器闭包。

## 缓存及清理机制

| 资源 | 保留规则 | 清理时机 |
| --- | --- | --- |
| 原始壁纸图片 | 每个壁纸缓存最多 2 张 | 最近使用淘汰、取消未完成的加载、加载失败、改用普通背景、最后一个玻璃 surface 卸载 |
| 生成的基础及边框纹理 | 最多 2 组，每组 2 张 | 淘汰、解码失败、任务取消、缓存销毁；移除图片源并 revoke Blob URL |
| Worker / ImageBitmap | 每个缓存只有一个当前渲染任务 | 完成、失败、任务取消或销毁；迟到的 bitmap 也会 close |
| 临时 Canvas | 仅在渲染/编码期间使用 | 完成或异常时将绘图缓冲宽度清零 |
| 液态玻璃 Canvas / WebGL | 液态模式期间按预算分配 | 退出液态模式释放 context、纹理、buffer、shader 和画布；滚出视口或暂停时清理输出画布 |
| 观察器、监听器、定时器、帧回调 | 随对应控制器存在 | 最后一个 surface 卸载或控制器销毁时取消 |
| 弹层及导航 SVG 背景滤镜 | 随弹层/导航挂载 | 对应卸载时移除节点、监听器和观察器 |
| 壁纸选择器列表 | 仅缓存 light / dark 两组文件名 | 组件生命周期内复用，卸载后可回收；列表不持有解码图片 |

切换到卡片模式时，少量纹理可以继续保留以供快速切回，数量仍有上限。稳定状态最多 4 个纹理 Blob URL；替换过程中可短暂出现 6 个，待新纹理解码完成并淘汰旧组后回到 4 个。
