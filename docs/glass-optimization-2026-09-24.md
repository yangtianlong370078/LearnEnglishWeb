液态玻璃无降画质优化（2026-09-24）

本次以保持原有显示效果为前提：普通玻璃/卡片 8px、液态 4px，背景实际 DPR、液态像素预算、折射曲线、色散、圆角、边框和菜单过渡均保留。基于此前性能分析，优先处理无效工作和资源滞留，没有采用降低分辨率、关闭色散或减少可见液态卡片来获得性能数字。

静态背景直接使用现有壁纸纹理，**没有增加 DOM 截图或 FBO 捕获**。每个当前背景资源在渲染器内上传一次，主题、尺寸或资源变化时更新；滚动只改变卡片采样坐标并复用纹理。不能把卡片折射结果也固定为一帧，否则滚动时背景对应位置会错误。

具体修改：

- 当前模式的照片和渐变模糊生成也移至 Worker＋OffscreenCanvas。当前任务优先，备用半径仍在当前背景发布后的 rAF＋idle 中准备；选择进行中的预热直接复用，尺寸/主题变化取消过期 Worker。保持原始像素尺度、模糊、颜色、padding、噪声和编码参数。
- Worker 不可用/失败时使用原 Canvas 回退，不把取消当失败，不发布过期结果。兼容 Canvas 的同步工作或已启动的编码无法强行中断，但会在绘制前和编码后检查取消并释放临时资源。
- 液态 atlas 和各卡片 Canvas 保留完整布局、固定尺寸与原采样分辨率；只为视口附近区域生成片元。裁片按原物理像素网格向外取整，保留至少一像素护边，并按 32px 块变化以减少裁片边界变动。保留完整卡片坐标、圆角计算和 DOM 层级。
- 逐卡片复制使用原完整 tile、完整目标画布，保留浏览器原有的完整画布复制路径；滚动不因裁片变化调整画布尺寸或 CSS 定位。atlas 绘制前清空，裁片外是透明像素，完整 `copy` 不保留旧帧残影。复用未变化卡片的已绘制画布，原始几何数据比较替代整组 JSON 字符串比较，只处理当前有画布的表面。
- 片元 Shader 使用 `smoothstep` 边缘支持范围 mask 乘到折射/色散偏移，没有动态 `if` 或 `discard`。mask 在原折射曲线非零区域恒为 1，保留原透镜形状；Fresnel 配置为 0 时在编译期省去无效光照计算。现有色散也是编译期变体，不是每片元动态分支。
- 导航栏忽略液态装饰 Canvas 的增删通知，避免仅绘制层变化又触发一轮全卡片几何读取；真实内容和布局变更仍正常处理。
- 修复模式选择器过渡跟踪的节点滞留。React Aria 全局 `transitionsByElement` 对同一元素多属性过渡取消只监听一次，可能留下未取消属性并持有卸载弹层。Popover ref 释放时调用公开 `runAfterTransition`，触发库已有的 detached element 清理；保留原 CSS 过渡、焦点和键盘交互。显式声明已安装版本的 `@react-aria/utils` 依赖。

**限制与取舍**

- 裁剪减少片元范围；完整 atlas 与完整卡片 Canvas 均保留以稳定分配，不声称它们的常驻显存同步下降。逐卡片复制仅跳过画面未变化的卡片，不声称其余卡片的复制面积变小。
- 双半径生成缓存仍按原 DPR 保存，没有靠降低分辨率缩减背景内存。前台 Worker 减少主线程串行工作，但总生成时间仍受调度、解码、传递和 GPU 竞争影响，不能保证每次更快。
- 本次保留原有严重慢帧保护，不增加更激进的关色散、降像素或减少卡片的自适应档位。那些措施会改变可见效果，与本次画质约束不符。
- 浏览器测量为 Windows / Chrome / Iris Xe；移动为布局与输入模拟，不是真机温度、电池和 Safari 测试。rAF 回调频率不等于屏幕呈现 FPS。
- 短时循环确认已定位的节点/监听器保留链消除，不能推出所有 JS heap、浏览器原生资源或数小时使用都绝无增长。
